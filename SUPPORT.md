# Wcash Wallet desktop support

## Current support boundary

There is no supported stable Wcash Wallet desktop release. The published files
are unsigned developer Mainnet candidates and are unsupported for material
funds. The project does not promise recovery, reimbursement, compatibility, or
response times for candidate use.

Before filing a non-security issue, read the current candidate limits in
[README.md](README.md), confirm the exact release tag, platform, architecture,
and source revision, and remove wallet secrets and personal data from logs.

## Public support and bug reports

Use [GitHub Issues](https://github.com/w-cash/wallet-desktop/issues) for public,
non-sensitive bug reports about this repository. Include:

- candidate tag or full source revision;
- operating system and CPU architecture;
- exact steps and expected/observed behavior; and
- redacted logs, if they are necessary to reproduce the problem.

Never post a seed phrase, spending key, full viewing key, wallet backup,
credential, or other private wallet material. The project cannot recover a lost
phrase or reverse a confirmed blockchain transaction.

For a suspected vulnerability, use the private route in
[SECURITY.md](SECURITY.md) instead of a public issue. Wcash support does not use
ZingoLabs' support channels or disclosure addresses.
